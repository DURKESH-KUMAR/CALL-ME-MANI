# 🤖 CALL ME MANI – Personal Assistant Chatbot (Python)

**CALL ME MANI** is a desktop-based **personal assistant chatbot** developed using **Python**. This intelligent assistant responds to voice commands, speaks answers back using text-to-speech, fetches information from **Wikipedia**, and provides a user-friendly interface built with **Tkinter**.

---

## 🧠 Overview

- **Project Name**: CALL ME MANI
- **Type**: Personal AI Assistant / Chatbot
- **Language**: Python
- **Interface**: GUI via Tkinter
- **Interaction**: Voice Input + Text Output + Speech Response
- **Status**: Functional Prototype

---

## ✨ Key Features

- 🎙️ **Voice Command Recognition**  
  Understands your spoken commands using the `speech_recognition` library.

- 🗣️ **Text-to-Speech Response**  
  Uses `pyttsx3` for clear, natural voice output.

- 🌐 **Wikipedia Integration**  
  Fetches quick summaries and facts from Wikipedia.

- 💬 **GUI Chat Interface**  
  Simple and interactive user interface built with `tkinter`.

- ⌨️ **Fallback to Text Input**  
  Supports both voice and manual text input for accessibility.

---

## 🛠️ Technologies Used

- **Python 3.x**
- [`tkinter`](https://docs.python.org/3/library/tkinter.html) – GUI creation  
- [`pyttsx3`](https://pypi.org/project/pyttsx3/) – Text-to-speech engine  
- [`speech_recognition`](https://pypi.org/project/SpeechRecognition/) – Converts speech to text  
- [`wikipedia`](https://pypi.org/project/wikipedia/) – Fetches article summaries  
- [`pyaudio`](https://pypi.org/project/PyAudio/) – Microphone access
