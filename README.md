# CALL-ME-MANI 🤖

**CALL-ME-MANI** is a friendly AI-powered chatbot application built to support mental health. This bot engages in human-like conversations and provides emotional support, acting as a digital companion for individuals who need someone to talk to.

The project was ideated and developed during **ENVISION** conducted by **IIC LICET** as part of a team submission. It leverages technologies in artificial intelligence and natural language processing to provide empathetic and meaningful conversations.

## 🌟 Features

- 💬 AI-driven conversational chatbot
- 🧠 Mental health-friendly response tone
- 💻 Simple and clean user interface
- 🌐 Works on the web (can be extended to other platforms)
- 🎯 Designed for accessibility and inclusivity

## 🛠️ Tech Stack

- **Python** – Core scripting and logic
- **OpenAI GPT API** – For generating natural, empathetic responses
- **Flask** – Lightweight web server
- **HTML/CSS/JavaScript** – Frontend interface
- **Bootstrap** – UI styling
